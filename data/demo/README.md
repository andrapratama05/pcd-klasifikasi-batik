# data/demo/

Letakkan foto batik baru di sini (`.jpg`, `.jpeg`, `.png`, `.bmp`, `.tif`, `.webp`) untuk diuji dengan model terbaik:

- notebook `notebooks/06_demo_klasifikasi.ipynb` (bagian 2), atau
- terminal: `uv run python -m src.predict data/demo/`

Foto tidak perlu persegi; bagian tengahnya otomatis dipotong menjadi persegi lalu dikecilkan ke 256×256. Foto di folder ini tidak ikut di-commit (hanya file README ini).
